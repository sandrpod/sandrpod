# docs-site

The public documentation site, at <https://docs.sandrpod.com>.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # → .vitepress/dist
```

## The two audiences

Every page is written for a person and fetchable by an agent. The build emits, in
addition to the HTML:

| Output | What it is |
|---|---|
| `/<page>.md` | the Markdown the page was generated from, at the page's URL |
| `/llms.txt` | the index, with one line per page and a `.md` link |
| `/llms-full.txt` | every page concatenated, for a single fetch |

Two buttons on every page come from `.vitepress/theme/CopyForLLM.vue`: **Copy for
LLM** puts the page on the clipboard with a source header, **View as Markdown**
opens the `.md` twin.

`buildEnd` in `.vitepress/config.mts` writes all of it (`llm.ts`); nothing is
generated by hand.
